# Programación 1
Este repositorio contiene los programas y ejercicios
desarrollados durante la materia de Programación 1.
Los ejercicios están organizados por temas, y cada
programa se encuentra en su propia carpeta.

## Programas incluidos


### BlackJack
Juego de un jugador, el que llegue a 21 gana.

### Casa Con Asteriscos
Crea una casa con asteriscos.

### Cifrado de palabras
Ingresa una palabra y tu puedes cifrarla o decifrarla, con los desplazamientos que tu eligas.

### Crea un Rombo
Programa para crear un rombo con la altura que tu quieras y con los simbolos que tu desees.

### Juego De luces
juego que consiste en apagar todas las luces.

### Sacar Curp
Programa para sacar tu curp ingresando tus datos.

### Curp
Instrucciones para ejecutar el programa
1. Requisitos previos
- Tener una computadora con Windows, Linux o macOS.
- Tener instalado Python 3.
- Contar con un editor de código, como Visual Studio Code.

2. Guardar el programa

1. Abrir Visual Studio Code o el editor de Python.

2. Copiar y pegar el código completo del generador de CURP.

3. Guardar el archivo con el nombre generador_curp.py.

4. Verificar que el archivo tenga la extensión .py.

3. Ejecutar el programa

Si se utiliza Visual Studio Code:
1. Abrir el archivo generador_curp.py.
2. Abrir una terminal desde el menú Terminal → Nueva terminal.
3. Escribir el siguiente comando:
python generador_curp.py

4. Presionar Enter para iniciar el programa.

4. Ingresar los datos solicitados

El programa solicitará los siguientes datos:
- Primer nombre.
- Segundo nombre (opcional).
- Primer apellido.
- Segundo apellido (opcional).
- Año de nacimiento.
- Mes de nacimiento.
- Día de nacimiento.
- Género.
- Estado de nacimiento (seleccionando el número correspondiente).
5. Obtener el resultado
Una vez ingresados todos los datos correctamente, el programa realizará las operaciones correspondientes y mostrará en pantalla los primeros 16 caracteres calculados de la CURP.
